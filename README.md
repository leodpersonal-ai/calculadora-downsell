# DosiVet — página de downsell

Página estática em espanhol com a oferta de US$ 8,90 por US$ 5,90, pagamento único e acesso vitalício. O desconto de 33,71% é apresentado arredondado como 34%.

## Arquivos

- `index.html`: conteúdo e espaços para os dois botões da Hotmart.
- `styles.css`: layout responsivo, sem fontes ou bibliotecas externas.

## Botões da Hotmart

No `index.html`, substitua o botão de prévia dentro de `#hotmart-accept` pelo código de aceitação fornecido pela Hotmart. Substitua o botão dentro de `#hotmart-decline` pelo código de recusa. Insira também qualquer script exigido pela plataforma, conforme a documentação do código fornecido.

Os botões de prévia ficam desabilitados para não simular uma compra ou recusa antes da integração. Os textos sugeridos são:

- Aceitar: **SÍ, QUIERO APROVECHAR MI DESCUENTO**
- Recusar: **No, gracias. Prefiero continuar sin la calculadora.**

## Visualização e hospedagem

Abra `index.html` para visualizar a página. Os dois arquivos da página podem ser servidos diretamente em uma hospedagem estática, sem instalação ou compilação. Valide a aceitação e a recusa no funil da Hotmart após inserir os códigos reais.
